## 推荐改动

保留**当前冻结模型**，把“行情分析端只读分钟缓存”提升为候选接入路线：

`D:\Download\行情分析端\DATA\DriverRTA\MIN.DY2` → 只读行情区快照 → 与训练 CSV 全字段谱系核验 → 原规则/特征/模型 → 既定 SQLite 账本及控制台。

HTTP 可继续用于独立观察/差异调查，但不能与缓存拼接、自动切换或混算命中率。尚未证明缓存持续更新：本轮观察 MIN.DY2 修改时间仍为 2026-10-27 23:59:17；当前会话不能取得 isky 主窗口标题。不能把这份缓存称为实时源。

新增缓存适配器只读获准的行情字段、必需结构/活动索引；不读取保留区、账户文件、凭证或其他进程内存。文件变化必须通过一致性检查；数据源品种/周期不能确定就暂停。输入稳定不能独自证明已收盘，仍需实测形成中根→完整根的机制。

不重训、不改模型和阈值、不安装依赖、不启动/登录/修改客户端。若需要用户将客户端切换到目标品种的一分钟图并保持更新，只说明可执行步骤，由用户操作；不能借缓存历史默认为当前订阅正确。
