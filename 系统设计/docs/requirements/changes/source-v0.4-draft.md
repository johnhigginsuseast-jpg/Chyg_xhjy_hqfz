# CR-RT-003：现有模型的HTTP独立跨源前向研究（v0.4，已确认）

状态：CONFIRMED。用户明确回复“批准 HTTP 跨源研究（推荐）”；确认前快照和摘要位于 `docs/baselines/v0.4/`。允许按下述范围实施，不关闭原有同源接入缺口。

## 为什么提出

原生磁盘缓存与训练数据数值一致，却未持续落盘；普通桌面DDE探测已能启动，但未取得Link，候选SkyServer/Min1未建立连接。不能断言所有官方接口均不可用，继续同源路线仍需可验证的官方连接/字段资料。

交易客户端已有的HTTP接口能返回正确的531/印江花果红茶二期。20:47:42实测返回20:47标签的行情；连续分钟观察证据另外保留。HTTP与训练CSV的价量/标签并不完全等价，因此不能冒称“原生同源输入通过”。

## 两种可审查选择

1. 保持v0.3同源门槛：保留已有基础代码，继续等待/调查官方接口资料；实时预测仍未接通。
2. 本次变更：**允许当前冻结模型在HTTP源上进行独立的实时跨源研究**，真实发出预测并统计未来命中率，同时明确数据域发生变化，不把其表现推广成原生同源模型的表现。

本变更不调模型、不重训、不改阈值、不承诺准确率。它改变的是“允许研究输入的来源资格”，不是通过技术转换证明数据等价。源差异可能改变模型表现，这正是新前向实验需要测量的内容。

## 研究版明确边界

- 单一HTTP531源，固定目标名称、period=0；TLS正常校验，凭证/账户/交易接口均不接触。
- 新建独立部署及SQLite统计空间，标记 `HTTP_CROSS_SOURCE_RESEARCH`、`domain_shift_acknowledged=true`、`research_only=true`；原生缓存、原历史留出及其他研究的预测不混入。
- 训练源仍记为 `supplied-20261028-native-csv`，实际推理源记为HTTP；保留原模型文件/元数据/来源检查，不修改训练来源字符串或冒用旧来源。
- 仅使用HTTP自身的真实历史引导窗口（预计接口可取约6000根，真实数量以实测为准）；冻结引导数据、起点与初始过滤状态。不得与原CSV拼接，不声称其EMA/规则起点与原生训练历史完全相同。
- 使用原共享规范化、三连跳两根、64有效根热身、39特征、原概率及阈值；每条记录留真实时间、输入和模型摘要。变化后的起点/分布影响如实保留。
- 先实测HTTP时间标签、服务器时钟、形成中根与后继根的关系。若证实原标签为开盘标签，保留原始时间，另外记录经验证的完整根结束时间；不是静默把数据平移一分钟。
- 成交量/成交额保留HTTP原始数值及源单位状态，不按客户端显示代码盲乘100。数值域与原训练量纲的未解释差异明确展示，不能包装成概率已经在新域校准。
- 只预测启用后的新完整有效根。断线补回只恢复状态/结算，迟到和不确定数据不进入正式前向分母；低置信度wait仍计入主方向命中率。
