# 日线小样本研究需求 v0.2

范围依据本聊天2026-10-30用户明确变更；差异和理由见change-request-v0.2.md。保留旧v0.1文档副本及原实验。不是修改原项目v1.0验收记录。

| 编号 | 必需行为 |
|---|---|
| DFR-01 | 重新只读审计原始日线/同源分钟：日期、字段、有效根数、缺失/重复/非有限数/价格逻辑/量异常、标签、逐日OHLC差异、数据可用时刻和未知元数据 |
| DFR-02 | 使用return_1、return_3、close/SMA5-1、5根收益率样本标准差四个特征；rolling min_periods等于窗口，无填补；实际首个全有效特征行位置5；仅h=1 |
| DFR-03 | 原有效日线150根固定前120开发、末30留出；开发内两个扩展窗口；所有拟合/验证标签目标严格早于下一分界；不随机切分 |
| DFR-04 | 沿用拟合>=80、验证>=10且各两类；最终测试不足10或单类标无法评估；不改门槛。逻辑回归使用训练段StandardScaler，C仅0.1/1.0，seed=20261028；验证平均平衡准确率选C，同分选0.1 |
| DFR-05 | 基线永远涨、永远跌、上一根相邻收盘方向；上一根持平时固定预测涨。固定阈值0.5，原始未校准概率。无删低置信度预测，无额外概率校准或阈值搜索 |
| DFR-06 | 每区间报告原根、热身、预测锚点、上下平未结算、边界隔离、二分类实数；报告逐折和留出准确率、平衡准确率、混淆矩阵及小样本不确定性；训练内拟合预测不当作能力证据 |
| DFR-07 | 每根日线保留账目；热身明确不可预测。所有符合规则的锚点保留方向、概率、原日期、可用/逻辑预测时间、实际执行UTC、版本、拟合信息、样本角色/标签状态；持平、跨边界、尾部未结算亦保留预测 |
| DFR-08 | 先保存预注册、代码/数据/文档哈希和完整切分；开发选参后保存模型及冻结清单；一次解锁本轮历史留出，不根据其结果修改设计。既往已暴露历史始终注明 |
| DFR-09 | 保存独立run-id的配置、模型、逐根预测、执行日志、数据/代码哈希、决策和结果；比较执行前后原项目与8CSV哈希；相关因果/门禁/持久化/独立复算与旧回归检查 |

时间规则沿用原项目：周一到周五三段，周六日盘、周日休息；没有记录即按用户研究口径休息，不补K线；日线午夜为交易日标签，研究假设当日16:00完成，须存在同源当日16:00分钟收盘且最后分钟收盘与日线相等。原生无时区时间保留，品种代码/时区/平台正式日历/单位均UNCONFIRMED。不使用小时/星期特征，不应用仅限1分钟的三连跳两根规则。

该产物是可审查的离线研究实验，不代表稳定信号、概率可靠、真实交易或全新盲测。若比较不稳或不优于基线，明确结论“未得到可靠预测信号”。
