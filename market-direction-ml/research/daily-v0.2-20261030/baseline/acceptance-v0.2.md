# 日线小样本研究独立验收标准 v0.2

对应requirements-v0.2.md；本次范围由用户明确请求授权，设计选择依此前推荐代选授权登记。不覆盖旧验收标准。不以预测准确率达到某个百分比作为软件通过条件。

| 编号 | 关联 | 判定标准 |
|---|---|---|
| DAC-01 | DFR-01,09 | 原始8CSV及旧项目（排除venv/缓存/本实验目录）前后文件名和SHA256全部相同；审计真实150根及分钟差异明细，严重结构错误阻止训练 |
| DAC-02 | DFR-02 | 恰四个已登记特征，实际热身5，前缀截断/未来扰动不改变历史特征；没有填补数据，无h>1训练 |
| DAC-03 | DFR-03,04 | 两折及最终拟合索引、目标时间、分界真实可查；拟合>=80且两类，验证>=10且两类，测试同10/两类；不足写无法评估，无降低门槛 |
| DAC-04 | DFR-04,05 | C仅0.1/1.0，缩放器只拟合实际训练索引；选参仅开发折，固定0.5；三基线同锚点计分；明确概率未校准 |
| DAC-05 | DFR-06 | 区间样本账目平衡，涨跌/持平/未结算/隔离分列；准确率/BA/固定行列顺序混淆矩阵逐折及测试可由预测独立复算；训练准确率不用于能力结论 |
| DAC-06 | DFR-07 | 150根都有账目；145个特征就绪锚点的四模型预测均留存；开发/训练内、扩展验证、历史测试、热身/平盘/待结算/隔离状态明确；概率和为1、时间和版本齐全 |
| DAC-07 | DFR-08,09 | 预注册先于拟合和留出指标；模型冻结先于一次留出解锁；拒绝覆盖run-id和二次计分；代码/数据/配置/文档/模型哈希匹配；重载预测一致 |
| DAC-08 | DFR-06,09 | 自动检查与原项目回归有命令、退出码和实际日志；七类测试材料及独立验收结果分开；如实记录FAIL/BLOCKED/NOT_TESTED，不以测试通过代替研究优势 |

预先登记研究优势门槛（独立于DAC软件/程序检查）：验证两折中严格多数折的LR准确率高于该折最强基线；历史留出LR准确率和BA均严格高于最强基线，且对每个基线的配对准确率差值95%成块自助区间下界均>0。固定block=5个连续有效日线、2000次、seed=20261028；每个模型准确率另报Wilson 95%区间（相关序列时只作描述，不当严格独立伯努利置信保证）。两折数量少、测试历史已暴露，纵使达到数值条件亦须未来未暴露数据确认，不宣称已获得稳定可交易能力。任一条件不满足，研究信号资格FAIL，并写“未得到可靠预测信号”。

未校准概率、真实来源/时区/官方日历、未来前向验证、实时接入与实盘为明确未核实或NOT_TESTED事项；本研究不把它们包装成通过。新近足够样本方可另立校准/多跨度研究。
